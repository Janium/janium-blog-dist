La constancia de no adeudo de Janium 2027 puede salir como documento Word, además del HTML que ya existía. Al emitirla, el navegador descarga un archivo cuyo nombre es el número de cuenta. La versión está en Janium 2027 ya está disponible.

Qué plantilla se usa

Para cada biblioteca el sistema busca en este orden: el Word de esa biblioteca, un Word genérico para todo el sistema, el HTML de esa biblioteca y, al final, un HTML genérico. La primera que existe es la que se usa. Si no hay ninguna, esa biblioteca no aparece al elegir dónde emitir la constancia.

Con una plantilla genérica basta para empezar. Cuando una biblioteca necesita otro membrete u otro texto, la suya tiene prioridad sobre la genérica.

El archivo Word

La plantilla es un .docx de Word o de LibreOffice, guardado como docx. El formato .doc antiguo no sirve. En el texto van marcas que el sistema sustituye por el nombre, la cuenta, la biblioteca y el perfil de la persona, entre otros datos de la ficha.

Cada marca tiene que quedar como un solo tramo de texto. Si el formato (subrayado, negrita o color) parte la marca por dentro, la constancia no se genera y el sistema dice cuál se rompió. Un archivo dañado tampoco produce el documento.

Quién la recibe no cambia

Esta versión cambia el archivo que se entrega, Word o HTML, según la plantilla que exista. Quién puede recibirla sigue igual que antes.

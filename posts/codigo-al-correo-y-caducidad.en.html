Janium 2027 can require, at sign-in, a code sent to email and a password change when the period set by the institution ends. Each function is turned on separately. The version is in Janium 2027 is now available.

Email code

The code is not asked of everyone. It is asked of anyone who already has an email address on the profile. After the username and password have been entered, Janium sends a six-digit code to that address. The code expires after ten minutes and arrives by email, without an authenticator app.

With no email, sign-in does not change: username and password, as before. For the function to apply, the email has to be registered. 2027 has no way to require the code from someone who does not have one, or when the message does not arrive.

Password expiry

When the period set by the institution ends, a new password has to be chosen at sign-in, before the system opens. This applies to staff and to anyone who looks up their account or places holds in the OPAC. Whoever administers the system sets the length and complexity of the password.

Limits

Neither function is active until the institution turns it on. The end of the period does not change the password on its own: it asks for a new one at the next sign-in.

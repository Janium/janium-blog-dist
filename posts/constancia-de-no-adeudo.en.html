The certificate of no debt in Janium 2027 can come out as a Word document, in addition to the HTML that already existed. When it is issued, the browser downloads a file named with the account number. The version is in Janium 2027 is now available.

Which template is used

For each library the system looks in this order: that library’s Word file, a generic Word file for the whole system, that library’s HTML, and last a generic HTML. The first one that exists is the one used. If none exists, that library does not appear when choosing where to issue the certificate.

One generic template is enough to start. When a library needs a different letterhead or different wording, its own template takes precedence over the generic one.

The Word file

The template is a .docx from Word or LibreOffice, saved as docx. The older .doc format does not work. The text carries marks that the system replaces with the person’s name, account, library and profile, among other data from the record.

Each mark has to stay as one stretch of text. If formatting (underline, bold or color) splits the mark, the certificate is not generated and the system names the mark that broke. A damaged file does not produce the document either.

Who receives it does not change

This version changes the file that is delivered, Word or HTML, according to the template that exists. Who may receive one stays as before.

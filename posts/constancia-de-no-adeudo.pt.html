A declaração de não dívida do Janium 2027 pode sair como documento Word, além do HTML que já existia. Ao emiti-la, o navegador descarrega um ficheiro cujo nome é o número de conta. A versão está em O Janium 2027 já está disponível.

Que modelo se usa

Para cada biblioteca o sistema procura por esta ordem: o Word dessa biblioteca, um Word genérico para todo o sistema, o HTML dessa biblioteca e, no fim, um HTML genérico. O primeiro que existe é o que se usa. Se não há nenhum, essa biblioteca não aparece ao escolher onde emitir a declaração.

Basta um modelo genérico para começar. Quando uma biblioteca precisa de outro cabeçalho ou de outro texto, o modelo dessa biblioteca tem prioridade sobre o genérico.

O ficheiro Word

O modelo é um .docx do Word ou do LibreOffice, gravado como docx. O formato .doc antigo não serve. No texto vão marcas que o sistema substitui pelo nome, pela conta, pela biblioteca e pelo perfil da pessoa, entre outros dados da ficha.

Cada marca tem de ficar como um único trecho de texto. Se o formato (sublinhado, negrito ou cor) parte a marca por dentro, a declaração não se gera e o sistema diz qual se partiu. Um ficheiro danificado também não produz o documento.

Quem a recebe não muda

Esta versão muda o ficheiro que se entrega, Word ou HTML, conforme o modelo que exista. Quem a pode receber mantém-se como antes.
